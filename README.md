# NASA Exoplanet Explorer Data Science Project
I started this data analysis project after listening to a fascinating lecture delivered by Warwick assistant professor and planetary scientist Dr Thomas Wilson for the University of Birmingham's Astronomical Society.<br>
The lecture on methods of identifying and characterising exoplanets in our galaxy was fascinating and reminded me of data science projects I'd seen online exploring NASA's exoplanet data.<br>
Since I'm taking a module on Data Science this semester, I thought it would be fun to finish my evening by looking at the data myself!<br>
